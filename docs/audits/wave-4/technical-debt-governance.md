# Technical Debt Governance

- Regular tech debt audits.
- Tech debt backlog tracking.
- Allocation of sprint capacity for debt reduction.

## Process

Toda nova dívida deverá possuir:
- **ID**: Unique identifier.
- **Responsável**: Owner of the debt.
- **Impacto**: Impact on the system (High, Medium, Low).
- **Prioridade**: Priority (Critical, High, Medium, Low).
- **Prazo**: Deadline for resolution.
- **Plano**: Remediation plan.
- **Status**: Current status.
