# Domain Map

Proposed Core Domains:
- **CRM Core**: Leads, Opportunities, Funnels, Interactions.
- **Intelligence**: Enrichment, Analytics, Scoring.
- **AI Platform**: Agents, Prompts, Memory, Gateway.
- **Platform Ops**: IAM (Identity & Access), Billing, Audit, Tenant Management.
- **Collaboration**: Notes, Comments, Mentions, Notifications.
